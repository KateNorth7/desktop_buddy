    How these numbers are made

    sumi sends no analytics. Everything here comes from records the service already keeps: an install is an anonymous built-in AI session; "in use" means the app refreshed that session (about once an hour while it runs); "recently online" means AI calls in the last hour, from per-minute counters kept for 48 hours. Installs that only use personal API keys are invisible. No names, IDs or content are shown or sent to this page.
