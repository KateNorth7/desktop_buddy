# sumi 0.52.0

sumi now understands each goal in the background, attributes short bursts of work to it, and closes simple goals by itself when the result is visible, with Undo.

- **Goal understanding.** Each open goal is interpreted once per revision from its own words, its done criterion, where it came from, recent work on it, relevant memory and recent chat messages about it, under the consent that already shares goals with goal matching. Existing goals are understood gradually after the update, one at a time. Goals can be written in any wording or language.
- **Closing finished work.** A goal to join a call, visit a site or send an email closes automatically with the existing Undo notice when sumi sees the result: a minute in the meeting, a few seconds on the named site, or the mail client's sent confirmation in English or Russian. A goal closes only when the result matches its target; pre-join screens, quoted or old confirmations, other recipients, other meetings, form errors and search results do not count. After real work on a goal without open steps ends, sumi asks once whether to mark it complete.
- **Episodes of work.** A settled match now owns its whole window context, quick returns to a window already tied to the same goal count toward it, and unassigned time is asked about after 45 seconds. When an episode ends, it is reviewed together: pending windows are attributed, supported results are proposed with a factual reason, and substantial work that fits no goal is offered as a new one. Findings made against an older version of a goal are dropped. Completion notices wait out quiet mode instead of being lost.
- **On-device text recognition.** When the active window exposes little readable text (messengers, canvases, remote screens) and **Use screenshots** is on, sumi recognizes its text on the device with Apple Vision on macOS and Windows OCR on Windows. The image is neither kept nor sent; the text is redacted and handled exactly like interface text. Settings and the privacy preview describe this.
- **Fixes.** On macOS, sumi no longer crashes in a loop on launch when its own window is in front. Goal matching waits its turn for the AI instead of skipping it, so time reaches goals reliably. Text recognition runs on the CPU with a four-second limit, so it can never stall tracking.

Tracking consent, exclusions, lock protection, encrypted evidence retention, the AI provider and model, cost limits and the trusted signing keys are unchanged.
